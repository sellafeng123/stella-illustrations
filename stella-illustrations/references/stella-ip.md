# Stella IP

## 角色定义

Stella 是中文正文配图的固定视觉 IP。

默认每张图都要出现 Stella IP。她不是贴纸或角落装饰，而是正在认真参与系统运转的温柔小创作者；她必须承担核心动作。

## 外形

- 厚实、略不齐的齐刘海；长直发从脸的两侧垂下并框住脸型。发型不可替换、不可缩短或改成其他轮廓。
- 头顶固定坐着一只小猫；左脸固定有薄荷绿星形痣；身侧始终出现一颗大薄荷绿星星。这三项与发型共同构成一眼可识别的记号。
- 淡紫 `#C9AFFE` 像素蜡笔线稿，带轻微颗粒与手绘抖动；薄荷绿 `#A5D8DD` 只做眼睛、星痣与大星等识别点。
- 简单连衣裙式身体，恰好两只小型、圆润、空心的淡紫线稿手和恰好两条淡紫线稿腿；双手必须从肩膀连续长出。
- 表情可随主题改变：思考时专注、压力时夸张惊讶、行动时坚定、发现时欣喜。需要警觉或互动时使用可爱的打开眼睛（圆润薄荷眼、高光），不要默认闭眼或方块眼。

## 性格

- 温柔、专注、有一点俏皮的想象力。
- 像在手账草图里真正负责某个工作的小创作者。
- 亲切但不幼态；可爱来自简洁识别点与主题表情，不是夸张卖萌。
- 认真执行动作，也允许有轻微的惊喜、好奇或压力反应。

## 常见职责

让 Stella IP 承担核心动作：

- 搬运素材。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器旁操作“判断”杆。
- 操作筛选漏斗。
- 切开“素材鱼”。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 从洞口旁协助承接内容。
- 搬运、搭桥、开门、分拣、记录。

## 禁止

- 不要改变刘海、两侧长直发、头顶小猫、左脸薄荷星痣或身侧大薄荷星。
- 不要画深色实心肢体、旧角色式肢体、手套、手指、第三只手、脱离肩膀的手、悬浮手或缺失身体。
- 不要把眼睛画成两个方块；不因图省事默认闭眼，表情必须贴合主题。
- 不要把 Stella IP 画成儿童海报角色、复杂时装角色或精致商业吉祥物。
- 不要让她只站在角落里看，也不要让她抢走结构表达。

## 判断标准

如果去掉 Stella IP，图的核心隐喻还能完全成立，说明她太装饰了；要重写提示词，让 Stella 成为动作主体。验收时逐项确认：固定发型、小猫、左脸星痣、身侧大星、完整裙装身体、两只连续连接的淡紫线稿手、两条腿，以及与主题匹配的可爱表情全部存在。
