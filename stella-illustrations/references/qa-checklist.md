# QA Checklist

## 必过项

- 是 16:9 横版。
- 背景是干净白底。
- 有完整、可识别的 Stella IP。
- Stella IP 承担核心动作，不只是装饰。
- 没有复刻旧案例构图，而是为当前文章生成了新隐喻。
- 画面温柔、有创意、有意思。
- 简洁清爽，主体不超过画面约 60%。
- 一张图只讲一个核心结构。
- 中文标注少、短、能读。
- 琥珀金只用于主路径、箭头、重点、问题、提醒或结果。
- 薄荷绿只用于 IP 识别点和少量次级结构。
- 深紫只用于强调、补充说明、反馈或系统状态。
- 厚实不齐的齐刘海、两侧长直发、头顶小猫、左脸薄荷星痣与身侧大薄荷星齐全。
- 恰好两只从肩膀连续连出的淡紫线稿手、恰好两条腿，且裙装身体完整。
- 表情与主题一致；需要警觉或互动时是可爱的打开眼睛，不是方块眼，也不默认闭眼。

## 失败信号

出现以下情况，重生成或局部编辑：

- 左上角有“常见坑 / Workflow / 系统架构图 / 路线图”等标题。
- Stella IP 缺少固定发型、小猫、左脸星痣或身侧大星，或被画成商业吉祥物/儿童卡通。
- 出现黑色旧角色肢体、额外肢体、第三只手、手指/手套、悬浮手、断开的手或缺失身体。
- 需要有反应的主题却默认闭眼，或把眼睛画成方块。
- 画面像 PPT、课程课件、正式流程图。
- 元素太多、箭头太多、节点太多。
- 文字变成大段解释。
- 背景有纸纹、阴影、渐变、米色、噪点。
- 真实 UI 截图或科技感界面。
- 中文错字严重或标注不可读。
- 画面太死板，没有荒诞隐喻。
- 和 `assets/examples/` 里的旧案例构图过于相似。

## 迭代方法

- 太普通：让 Stella IP 成为动作主体，加入一个温柔但成立的隐喻。
- 太复杂：删节点，只保留一个动作和 3-5 个短标注。
- 太幼态：强调 gentle explanatory article sketch、not children's poster、not commercial mascot；保留 Stella 的可爱识别点但不卖萌。
- 太 PPT：去掉标题、边框、整齐网格和过多箭头，改成手绘场景。
- 太像旧案例：保留核心意思，换掉主物件和 Stella IP 动作。
- 文字错：优先局部编辑；错得多就重生成并减少标注数量。

## 交付判断

高质量图应该让读者先感到“温柔又有一点巧思”，然后 1 秒内看懂结构。

如果第一眼像教程页、商业海报或儿童卡通，而不是白纸上的温柔像素蜡笔产品草图，就不合格。
